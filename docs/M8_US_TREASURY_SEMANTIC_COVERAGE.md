## Comparison and execution vocabulary

- **E0 / TOL-E0** means exact selected bits, canonical amount, endpoint,
  context or structured decision; **E1 / TOL-E1** is a once-correctly-rounded
  retained exact AI observation. **TOL-E0 primitive** refers to the prescribed
  factor/PV/term algorithm, not ideal-real correctly rounded pricing.
- **Conditional** means the frozen N3/N5 or inverse conditioning allowance,
  with source-PV admission and uninformative labels preserved. It is not a
  blanket ULP or relative subnormal comparison.
- **SOURCE** is independent primary/XML, Fraction/integer or corroborating
  Decimal work. It is separate from a Rust public runtime assertion.
- **PROOF / STATIC** identifies mathematical exclusions, width/lifetime or API
  inspection. **INHERITED M6** names a shared bounded-Brent protocol assertion.
  **Allocation-only** and excluded private capacity states are not manufactured
  financial runtime tests.
