## Primary artifact and checker

The only input is the official eCFR XML of 31 CFR Part 356 from the
[eCFR versioner](https://www.ecfr.gov/api/versioner/v1/full/2026-10-16/title-31.xml?part=356),
current through 2026-10-16. It is byte-identical to the 2026-10-15 version,
whose amendment changed only inflation-protected material. The checked
content is Appendix B, Formulas and Tables, for fixed-principal
("non-indexed") securities only:

* section I.A: coupons, Table 1 and Table 2;
* section I.D: accrued interest;
* section II A–G: yield-to-price worked examples.

The checker refuses any other XML bytes. It parses Appendix B structurally
with the standard-library XML parser and takes every printed cell from the
XML text, including table cells, worked lines and example statements. It never
types a printed cell in by hand. Statement dates used for day counts are
asserted verbatim in each example's own paragraph before use.

Exact Python `Fraction` arithmetic is authoritative. With an integer number of
periods every Section II quantity is exactly rational, so the prices, accrued
interest and clean candidates below are exact rather than approximated. A
separate Decimal route at 160 and 240 digits recomputes dirty price, accrued
interest and, in II.E, its two accrued components directly from the decoded
Decimal inputs, using Decimal powers and the closed-form annuity. It then
checks all three clean candidates below under both tie rules against
`Fraction`, including the source's printed price. Arithmetic, subtraction and
quantization stay inside each explicitly chosen precision. The `Fraction`
route sums the annuity term by term. The unrounded Decimal comparison uses
`abs(error) <= 10^-(precision-25) * max(1, abs(exact))`; it is a corroborating
second computation, not a proof. The price, accrued and clean checks cover
all seven examples; the I.A/I.D printed anchors are exact-rational checks.

## Rounding model

Appendix B prescribes "normal rounding procedures" for prices (six places per
100) and accrued interest (five places per $1,000) but does not state the tie
rule. Every comparison is therefore made under both half-away-from-zero and
half-even. The report flags every exact tie. No tie rule is chosen here.

Each value is the same under both tie rules. The source's printed trace

reproduce the print. The example therefore shows that raw-clean rounding
differs from the source, but it does **not** establish whether the dirty price
is rounded before subtraction. That stage remains a contract decision.

### Component accrued interest in II.E

The printed `AI′` (1.306630) plus `AI` (2.366168) equals the printed
`A` = 3.672798, which is also the six-place rounding of the exact total. A
single agreeing example cannot make component rounding mandatory. As a
**derived** control (not a source statement), an E-shaped reopening with
`C` = 10.75, `s″` = 181 and `s` = 184 was varied over `r′` = 1..180 and
`r` = 1..183. Per-component six-place rounding differs from rounding the exact
total in 8,320 of 32,940 cases. The first is `r′` = 1, `r` = 9: 5.141788
versus 5.141789. The choice is material in general.

## Scope and remaining decisions

Hard failures are limited to:

* pins and parse completeness;
* Tables 1–2 and the printed anchors;
* the seven printed prices through the source's own trace;
* the cross-section identity.

The independent Decimal computations, both tie rules, exact date checks and
rounding-helper controls are also asserted. Trace classification and derived
staging sensitivity remain informational.

Staging alternatives, tie sensitivity and unexplained intermediate cells are
reported, not resolved. This is a comparison of printed source cells, not a
frozen fixture, an interval proof or a binary64 production oracle. It does
not check the TreasuryDirect auction-price page, inflation-protected, floating
rate or bill sections, real auction announcements, a Federal Reserve closure
calendar or secondary-market entitlement.

A Treasury contract must still choose, with stated source-interpretation
qualifications:

* the tie rule;
* exact versus table-decimal coupon and accrued staging;
* component versus total accrued rounding;
* whether the dirty price is rounded before subtracting accrued interest;
* the II.E headline typo resolution.

It must also close the remaining gaps in the source review before independent
oracles and production.
