## Consumer and acceptance constraints

Exact rational ingredient columns in S/N are reference mathematics, not new
public ratio inspectors. Public source views/cash/metadata bind the specified
API; private numerical output binding requires an attested copy of the actual
kernel, including source widths and exponent/accumulator resource bounds.
Artificial seeds never certify a native public quote's reachability.

P compares each quantity with its own predeclared conditional error and value
class. Y's coordinate predicate uses the exact difference of represented cached
dirty/target values, quote membership in the supplied bracket and a positive
global slope bound. A rounded amount-residual getter alone is insufficient.
One observed MM image row has no ideal-root claim and prescribes the cached
upper FunctionZero protocol separately. No mismatch may widen these references.

The future acceptance report must record actual producer/reader/tool command
results, frozen artifact/source identities and every remaining R/A obligation.
After implementation, meaningful semantic mutants must fail running assertions;
compile failure is not a semantic kill. Complete native regressions, strict
lint/fmt/docs, Linux/Windows compilation, extracted package tests and measured
coverage retain their exact platform/scope. Financial/owner, foreign native,
maintained calendar/legal, release and wider M8 acceptance remain separate.
